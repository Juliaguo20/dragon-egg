# Dragon Egg Quest

A classroom AR treasure hunt for phones. Players turn around with the phone to find eggs and track flying dragons. Solve clues, scan 6 QR cards, hatch 3 dragons, power them up with gems, defeat the Storm Dragon and win back the Power Stone. About 8–10 minutes.

**Play:** https://juliaguo20.github.io/dragon-egg/

## Set up
1. Print `cards.pdf` at 100% size (page 1: QR cards, page 2: teacher sheet, page 3: paper clue slips).
2. Hide the cards as listed on the teacher sheet.
3. Open the game, choose **In-app clues** or **Paper clues**, and allow the camera and motion sensors.

If a card will not scan, tap **Type the code instead** and enter the code printed under it.
Edit clues in `content.js` (then update the teacher sheet).

## Publish (GitHub Pages)
Settings → Pages → Deploy from a branch → `main`, `/ (root)`.
